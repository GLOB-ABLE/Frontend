## 0. 왜 문항을 바꾸나

기존 나침반은 "어떤 국제기구가 나에게 맞나"를 묻는 진로 탐색이었습니다. 새 제품은 **"이 공고에서 내가 무엇이 충족되고 무엇이 부족한가"**를 판정합니다. 판정에 쓰이지 않는 질문은 빼고, 판정에 필요한데 없던 질문을 넣습니다.

**진단 답 → 쓰이는 곳**

```
진단 입력
  ├─ 체류자격·학적      → 게이트 상태 (VG-A~D) · 서비스 이용 범위 결정
  ├─ 학력·경력·어학·자격 → 공고별 요건 4상태 판정 (충족/미충족/확인 필요/해당 없음)
  ├─ 한국어 업무행동     → 공고의 "한국어 능통" 요건과 행동 단위로 대조
  ├─ 희망 조건          → 공고 추천·정렬
  └─ 증빙 보유 여부      → 충족 / 확인 필요를 가르는 기준
```

---

## 1. 반드시 지켜야 할 3가지

진단 문구를 쓸 때 아래는 예외 없이 지킵니다.

| #   | 규칙                            | 이유                                                                                                                             |
| --- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **국적을 조건으로 묻지 않는다** | 국적은 회원정보로만 보유하고, 추천·판정에는 쓰지 않습니다. "베트남어로 거래처 응대 가능"처럼 **언어·업무 행동**으로 묻습니다.    |
| 2   | **증빙 여부를 함께 묻는다**     | 자기 기입값만으로는 "충족"이 되지 않습니다. 증빙이 없으면 "확인 필요"로 표시됩니다.                                              |
| 3   | **점수·확률로 말하지 않는다**   | "매칭률 92%", "합격 가능성 높음" 같은 표현은 결과 화면에서 쓰지 않습니다. 항상 **개수**로 말합니다 (예: "요건 6개 중 충족 4개"). |

## 2. 문항 구성 — 4단계 · 총 14문항

| 단계   | 이름                   | 문항 수 | 소요   | 목적                                     |
| ------ | ---------------------- | ------- | ------ | ---------------------------------------- |
| STEP 1 | 지금 상태              | 4       | 약 1분 | 게이트 상태 판정 (서비스 이용 가능 여부) |
| STEP 2 | 내 조건                | 5       | 약 2분 | 요건 판정에 쓸 학력·경험·어학 데이터     |
| STEP 3 | 한국어로 할 수 있는 일 | 1       | 약 1분 | 공고의 "한국어 능통"과 행동 단위 대조    |
| STEP 4 | 원하는 일              | 4       | 약 1분 | 공고 추천·정렬 조건                      |

> 각 단계 끝에 저장 지점을 둡니다. 중간에 나가도 다음에 이어서 할 수 있게 합니다.

---

## STEP 1 · 지금 상태 (4문항)

> **화면 안내 문구**
> "먼저 지금 상태를 알려주세요. 쓸 수 있는 기능이 정해져요."

### Q1. 체류자격 — 필수 · 단일선택

**질문** 지금 가지고 있는 체류자격이 무엇인가요?

| 선택지                | 게이트 결과                        |
| --------------------- | ---------------------------------- |
| D-2 (유학)            | VG-B 또는 VG-C — Q2 답에 따라 갈림 |
| D-10 (구직)           | VG-A                               |
| E-7 (특정활동)        | VG-A                               |
| F-2 / F-5 / F-6       | VG-A                               |
| 그 외 / 잘 모르겠어요 | VG-D                               |

**도움말** "외국인등록증 앞면에 적혀 있어요."

---

### Q2. 학적 상태 — 필수 · 단일선택

**질문** 지금 학교를 다니고 있나요?

| 선택지                   | 비고                                                      |
| ------------------------ | --------------------------------------------------------- |
| 재학 중이에요            | D-2 + 재학 → **VG-C** (공고 추천·지원 차단)               |
| 곧 졸업해요 (6개월 이내) | D-2 + 졸업예정 → **VG-B** (공고 조회는 가능, 지원은 차단) |
| 이미 졸업했어요          | —                                                         |

**조건부 추가 질문** "곧 졸업" 또는 "이미 졸업" 선택 시 → **졸업(예정)일** (연·월)

> ⚠️ **한나님 확인 필요**
> VG-C(재학 중 D-2) 사용자에게는 공고를 아예 보여주지 않습니다. 이때 대신 보여줄 화면 문구가 필요합니다.
> 초안: "지금은 지원을 열 수 없어요. 졸업이 가까워지면 다시 열립니다. 그동안 할 수 있는 준비를 알려드릴게요."

---

### Q3. 체류 만료일 — 필수 · 날짜 입력

**질문** 체류 만료일이 언제인가요?

- 만료일이 지났거나 3개월 이내면 → **VG-D** (기능 잠금 + 보완 안내)
- 화면 표시 예: "만료가 3개월 남았어요. 연장이나 전환을 먼저 확인해 주세요."

---

### Q4. 외국인등록증 증빙 — 선택 · 파일 업로드

**질문** 외국인등록증을 올려주시겠어요?

**보조 문구** "올리지 않아도 진단은 됩니다. 올리면 체류 정보가 '확인됨'으로 바뀌어요."

---

## STEP 2 · 내 조건 (5문항)

> **화면 안내 문구**
> "공고 요건과 맞춰볼 내용이에요. 증빙이 있으면 '충족'으로, 없으면 '확인 필요'로 표시돼요."

### Q5. 최종 학력 — 필수 · 단일선택 + 입력

**질문** 최종 학력을 알려주세요.

- 학위: 전문학사 / 학사 / 석사 / 박사
- 전공 (자유 입력, 자동완성)
- 학교명 (자유 입력)
- 졸업(예정)일 → **Q2에서 이미 받았으면 생략**

**증빙** 졸업증명서 또는 졸업예정증명서 (선택 업로드)

---

### Q6. 한국어 능력 — 필수 · 단일선택

**질문** 한국어 시험 성적이 있나요?

| 선택지                             |
| ---------------------------------- |
| TOPIK 1~6급 (급수 선택)            |
| 사회통합프로그램 이수 (단계 선택)  |
| 시험은 없지만 일상 대화는 가능해요 |
| 아직 없어요                        |

**증빙** 성적표 (선택 업로드)

> **판정 예시**
> 성적표 없이 "TOPIK 4급" 선택 → 화면에는 **`? 확인 필요`**로 표시되고, 근거에 "성적표가 없어 충족으로 바꾸지 않습니다."가 붙습니다.

---

### Q7. 그 밖의 언어 — 선택 · 복수선택 + 수준

**질문** 한국어 말고 업무에 쓸 수 있는 언어가 있나요?

- 언어 선택 (베트남어 / 영어 / 중국어 / 일본어 / 기타)
- 각 언어별 수준: 원어민 수준 / 업무 가능 / 일상 대화

> ⚠️ **여기서 국적을 묻지 않습니다.** "베트남 출신"이 아니라 "베트남어 업무 가능"으로 받습니다.

---

### Q8. 일 경험 — 선택 · 반복 입력

**질문** 일해 본 경험이 있나요? (인턴·아르바이트·프로젝트 모두 포함)

각 경험마다:

- 어디서 (회사·기관명)
- 무슨 일을 했는지 (자유 입력 1줄)
- 기간 (시작 ~ 종료)
- 고용 형태: 정규직 / 계약직 / 인턴 / 아르바이트 / 학교 프로젝트

**증빙** 경력증명서 또는 재직증명서 (선택 업로드)

---

### Q9. 자격증 — 선택 · 복수 입력

**질문** 가지고 있는 자격증이 있나요?

- 자격증 이름 (자유 입력)
- 취득일
- **증빙** 자격증 사본 (선택 업로드)

---

## STEP 3 · 한국어로 할 수 있는 일 (1문항)

> **화면 안내 문구**
> "급수만으로는 알 수 없는 게 있어요. 실제로 할 수 있는 일을 골라주세요."

### Q10. 업무 행동 — 필수 · 복수선택 + 5단계

**질문** 한국어로 이런 일을 할 수 있나요?

| 업무 행동                          | 5단계                                                                |
| ---------------------------------- | -------------------------------------------------------------------- |
| 거래처 전화를 받고 내용을 전달하기 | 어려워요 / 도움이 있으면 가능 / 혼자 가능 / 익숙해요 / 매우 익숙해요 |
| 회의에서 진행 상황을 말하기        | 〃                                                                   |
| 메신저로 동료와 소통하기           | 〃                                                                   |
| 짧은 보고서 쓰기                   | 〃                                                                   |
| 고객 응대하기                      | 〃                                                                   |

> **왜 이렇게 묻나**
> 공고의 "한국어 능통"은 회사마다 뜻이 다릅니다. 어떤 곳은 전화 응대, 어떤 곳은 보고서 작성입니다. 행동 단위로 받아야 공고 해석 결과와 나란히 비교할 수 있습니다.

---

## STEP 4 · 원하는 일 (4문항)

> **화면 안내 문구**
> "어떤 공고를 보여드릴지 정하는 데 쓸게요. 나중에 바꿀 수 있어요."

| #   | 질문                         | 형식                                                               |
| --- | ---------------------------- | ------------------------------------------------------------------ |
| Q11 | 어떤 일을 하고 싶으세요?     | 복수선택 — 해외영업·무역 / 구매·자재 / 생산관리 / 경영지원 / 그 외 |
| Q12 | 어디에서 일하고 싶으세요?    | 복수선택 — 서울 / 경기 / 인천 / 충남 / 상관없어요                  |
| Q13 | 희망 연봉이 어느 정도인가요? | 슬라이더 — 2,600만원 ~ 4,500만원                                   |
| Q14 | 어떤 근무 형태를 원하세요?   | 단일선택 — 정규직 / 계약직 / 인턴                                  |

## 3. 결과 화면(04)으로 넘어갈 때

### 3.1 진단 직후 보여줄 것

| 순서 | 내용           | 표현 방식                             |
| ---- | -------------- | ------------------------------------- |
| 1    | 게이트 상태    | VG-A~D 배너 + "쓸 수 있는 기능" 안내  |
| 2    | 내 조건 요약   | 입력한 항목을 카드로 정리 (수정 가능) |
| 3    | 확인 필요 항목 | "증빙 N개를 올리면 상태가 바뀝니다."  |
| 4    | 다음 행동      | **공고 보러가기 (버튼)**              |

### 3.2 공고 보러가기 — 버튼으로만

> ✅ **결정 사항 (2026-08-08)**
> 결과 화면 아래쪽의 공고 영역은 **버튼을 눌러야만** 공고 목록으로 이동합니다.
> 카드 전체를 클릭하거나, 스크롤로 자동 이동하거나, 미리보기 카드에서 바로 상세로 들어가는 경로는 두지 않습니다.
>
> **이유** — 진단 결과를 확인하지 않고 공고로 넘어가면 "왜 이 공고인지" 근거를 못 보고 지원하게 됩니다.

## 4. 기존 나침반과 달라지는 점

| 구분                | 기존 나침반                      | 내 조건 진단                                         |
| ------------------- | -------------------------------- | ---------------------------------------------------- |
| 목적                | 어떤 국제기구가 맞나 (진로 탐색) | 이 공고에서 뭐가 부족한가 (요건 판정)                |
| A/B 트랙 분기       | 있음 (흥미 / 고급)               | **없앰** — 판정에는 같은 데이터가 필요               |
| 체류자격            | 안 물음                          | **새로 추가** (Q1~Q4) — 서비스 이용 가능 여부를 가름 |
| 한국어              | 안 물음                          | **새로 추가** (Q6, Q10)                              |
| 증빙 업로드         | 없음                             | **새로 추가** — 충족 / 확인 필요를 가르는 기준       |
| 영어·제2외국어      | 수준만                           | 언어 + 수준 + 증빙 (Q7)                              |
| 연구 주제·석사 전공 | 있음                             | **뺌** — 요건 판정에 안 쓰임                         |
| 결과 표현           | 추천 기구 목록                   | 게이트 상태 + 조건 요약 + 확인 필요 항목             |

## 5. 한나님께 여쭤볼 것

| #   | 항목                                         | 왜 필요한가                                                                                             |
| --- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | **VG-C(재학 D-2) 화면 문구**                 | 공고를 못 보는 사용자에게 뭐라고 안내할지. 서비스를 떠나지 않게 하는 문구가 필요합니다.                 |
| 2   | **문항 수 14개가 적당한지**                  | 이탈률이 걱정되면 STEP 2·4를 나중에 물어보는 방식(공고 볼 때 그때그때)으로 바꿀 수 있습니다.            |
| 3   | **증빙 업로드를 진단 안에 둘지**             | 진단 중에 파일을 올리게 하면 이탈이 큽니다. "나중에 올리기"를 기본으로 하는 안도 가능합니다.            |
| 4   | **다국어 범위**                              | 한국어 능력이 낮은 사용자가 한국어 진단을 못 채웁니다. 최소한 STEP 1은 영어·베트남어가 필요해 보입니다. |
| 5   | **결과 화면에서 공고를 몇 개 미리 보여줄지** | 0개(버튼만) / 3개 미리보기 중 어느 쪽인지. 위 3.2는 "버튼만"으로 적어뒀습니다.                          |
