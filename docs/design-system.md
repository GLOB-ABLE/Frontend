## 3. A · 4상태 배지

모든 화면에서 **같은 색·같은 아이콘·같은 말**로 씁니다.

### 3.1 상태 정의

| 상태      | 아이콘 | 의미                                      |
| --------- | ------ | ----------------------------------------- |
| 충족      | `✓`    | 증빙으로 확인됨                           |
| 미충족    | `✕`    | 요건과 다름이 확인됨                      |
| 확인 필요 | `?`    | 증빙이 없거나 불충분 — **가장 자주 등장** |
| 해당 없음 | `–`    | 이 공고의 요건 목록에 없음                |

### 3.2 크기 변형

| 크기   | 사용처    | 폰트   | 굵기 | 패딩      | radius | gap | 아이콘      |
| ------ | --------- | ------ | ---- | --------- | ------ | --- | ----------- |
| Small  | 표 안     | 12px   | 700  | 5px 10px  | 6px    | 5px | 텍스트 11px |
| Medium | 카드      | 13.5px | 700  | 7px 13px  | 8px    | 7px | 원형 16px   |
| Large  | 판정 헤더 | 16px   | 800  | 11px 18px | 11px   | 9px | 원형 22px   |

- Medium/Large 아이콘은 **원형 배경 + 흰색 글리프**. 배경은 상태 코어 색상.
- 배지 배경/보더/텍스트는 1.2의 상태 색상 세트를 그대로 사용.

### 3.3 펼침 동작

배지를 누르면 **판정 근거**가 열립니다. 근거 없이 판정만 보여주지 않습니다.

**구조**

```
[행 헤더]  요건명 / 요구 조건  ·  [상태 배지]  ·  [▼ / ▲]
  └ (펼침) 판정 근거
       · 사실 문장 1
       · 사실 문장 2
       · 사실 문장 3
     [근거 칩들]                        [주요 액션 버튼]
```

**예시 — 확인 필요 (기본 펼침)**

> **한국어 능력** · 요구 TOPIK 4급 — `? 확인 필요`
>
> 판정 근거
>
> - 본인이 적은 값은 TOPIK 4급입니다.
> - 성적표 파일이 올라오지 않았습니다.
> - 증빙이 없어 충족으로 바꾸지 않습니다.
>
> `근거 보기` `규칙 v1.2` `기준일 2026.03.01` → **성적표 올리기**

**예시 — 충족**

> **학위** · 요구 4년제 졸업 — `✓ 충족`
>
> - 졸업증명서를 확인했습니다.
> - 학교와 전공이 요구 조건과 같습니다.

**예시 — 미충족**

> **직무 경험** · 요구 수출 서류 업무 1년 — `✕ 미충족`
>
> - 적은 경험은 카페 근무 8개월입니다.
> - 수출 서류 업무 기록이 없습니다.
> - → **인턴 프로그램 보기**

**예시 — 해당 없음**

> **운전면허** · 이 공고에서 묻지 않습니다 — `– 해당 없음`
>
> - 이 공고의 요건 목록에 없는 항목입니다. 판정에 넣지 않습니다.

**행 컨테이너 스타일**

| 상태      | 보더      | 배경      |
| --------- | --------- | --------- |
| 확인 필요 | `#F3DFAE` | `#FFFBF0` |
| 충족      | `#D9EEE2` | `#F5FBF7` |
| 미충족    | `#F7D5D0` | `#FFF7F6` |
| 해당 없음 | `#E7EBF1` | `#FBFCFE` |

- radius 13px, 행 간격 10px, 헤더 패딩 16px 18px, 펼침 영역 패딩 18px + 흰 배경.
- 캐럿은 접힘 `▼` / 펼침 `▲`, 색상은 해당 상태 텍스트 색.

## 4. B · 요건 상태 요약 바

**%를 대체합니다. 라벨은 항상 개수입니다.**

### 4.1 규칙

- 칸 순서 고정: **충족 → 확인 필요 → 미충족 → 해당 없음**
- 높이 `10px` · 칸 간격 `3px` · radius `6px`
- **% 기호와 소수점은 쓰지 않습니다**
- 각 칸 flex 비율 = 해당 상태의 요건 개수

### 4.2 상태 변형 (요건 6개 기준)

| 시나리오              | 라벨                            | 구성                     |
| --------------------- | ------------------------------- | ------------------------ |
| 확인 필요만 남은 상태 | 충족 4 · 확인 필요 2            | 초록 4 / 노랑 2          |
| 미충족이 섞인 상태    | 충족 3 · 확인 필요 2 · 미충족 1 | 초록 3 / 노랑 2 / 빨강 1 |
| 모두 확인된 상태      | 충족 6                          | 초록 6                   |
| 아직 확인 못 한 상태  | 확인 필요 5 · 해당 없음 1       | 노랑 5 / 회색 1          |

### 4.3 공고 카드 적용 예

```
[로고 48px]  해외영업 담당 (신입)
             대성정밀공업
             경기 시흥 · 3,200만원 · 정규직

[베트남어로 거래처 응대] [수출 서류] [E-7 전환 지원]
────────────────────────────────────────
요건 6개                    충족 4 · 확인 필요 2
▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬  ▬▬▬▬▬▬▬▬
[근거 보기] [기준일 2026.03.01]        상세 보기 →
```

- 카드 보더 `#C9DFF8`, radius 14px, 패딩 20px
- 태그 칩: 배경 `#F1F7FF`, 텍스트 `#1F3A8F`, 보더 `#E2ECF9`

> ❌ **이렇게 쓰지 않습니다** — 매칭률 92% · 도넛 게이지 · 상위 12%

## 6. D · 책임 주체 태그

장애요인마다 **누가 움직여야 하는지** 붙입니다.

### 6.1 주체 정의

| 주체   | 도트         | 배경      | 보더      | 텍스트    |
| ------ | ------------ | --------- | --------- | --------- |
| 학생   | `#1F77FF`    | `#D7EDFB` | `#A9D2F5` | `#1F3A8F` |
| 기업   | `#137A70`    | `#DCF2F0` | `#A9DCD7` | `#0E5C55` |
| 공동   | 파랑+틸 겹침 | `#E7EBFB` | `#BFC6EE` | `#3B3F8F` |
| 전문가 | `#6D3FD6`    | `#EDE7FB` | `#CFC0F0` | `#4B2E91` |

- 도트 7px 원형, gap 6px, `padding 6px 12px`, radius 7px, 12.5px / 700
- 공동은 두 도트를 `margin-left:-3px`로 겹쳐 표시

### 6.2 장애요인 목록 적용 예

| 주체   | 소요     | 할 일                              | 설명                                  |
| ------ | -------- | ---------------------------------- | ------------------------------------- |
| 학생   | 예상 2주 | TOPIK 성적표를 올려주세요          | 올리면 확인 필요가 충족으로 바뀝니다. |
| 기업   | 예상 1주 | 고용계약서 초안이 필요합니다       | 기업이 올려야 다음 단계로 갑니다.     |
| 공동   | 예상 4주 | 직무와 전공 관계를 설명해야 합니다 | 학생과 기업이 함께 서류를 씁니다.     |
| 전문가 | 검토 3일 | 서류를 한 번 봐드립니다            | 행정사가 내용을 확인합니다.           |

- 카드 배경/보더는 해당 장애요인의 **상태 색**을 따릅니다 (확인 필요 → `#FFFBF0`/`#F3DFAE`, 미충족 → `#FFF7F6`/`#F7D5D0`).
- 소요 시간 텍스트는 12px / 600, 상태 텍스트 색과 동일.

## 7. E · 게이트 상태 배너

항상 화면 상단에 놓습니다. **차단 상태도 오류가 아니라 안내로 보이게** 합니다.

| 코드 | 제목                         | 설명                                                         | 액션                          | 배경 / 좌측 바                 |
| ---- | ---------------------------- | ------------------------------------------------------------ | ----------------------------- | ------------------------------ |
| VG-A | 모든 기능을 쓸 수 있어요     | D-10 · 체류 만료 2026.11.30 · 확인 필요 항목 없음            | 체류 정보 보기 →              | 그라디언트 `#1F3A8F → #1F77FF` |
| VG-B | 일부 기능이 잠겨 있어요      | 확인이 필요한 항목이 2개 있습니다. 지원은 계속할 수 있어요.  | 2개 확인하기 (프라이머리)     | 흰 배경 / `#E9A700`            |
| VG-C | 지금은 지원을 열 수 없어요   | 체류자격이 확인되면 다시 열립니다. 공고는 계속 볼 수 있어요. | 무엇을 하면 되나요 (아웃라인) | 흰 배경 / `#94A3B8`            |
| VG-D | 체류 정보를 아직 못 받았어요 | 외국인등록증을 올리면 상태를 확인해 드려요.                  | 등록증 올리기 (프라이머리)    | `#F7FBFF` / `#4B8BEF`          |

**스펙**

- radius 14px, `padding 18px 24px`, 요소 gap 18px
- 좌측 상태 코드 배지 (VG-A~D), 제목 15.5px / 700, 설명 13px
- 좌측 바 `border-left: 4px solid`

**규칙**

- 차단 상태(VG-C)에도 **레드를 쓰지 않습니다**
- 아이콘은 경고 삼각형 대신 **상태 코드 배지**
- 문장은 **무엇이 막혔는지**와 **다음에 할 일**만 씁니다

## 8. F · 면책·출처 푸터

## 9. 원칙 요약

1. **판정에는 항상 근거가 붙는다.** 근거 칩(C) 없는 판정 화면은 만들지 않습니다.
2. **숫자는 개수로만.** 확률·%·점수·순위·별점은 어떤 형태로도 쓰지 않습니다.
3. **증빙이 없으면 충족이 아니다.** 자기 기입값만으로 충족 처리하지 않습니다.
4. **상태 색은 판정에만.** 장식·아이콘·배너 배경에 상태 색을 쓰지 않습니다.
5. **차단도 안내로.** 막힌 상태에서도 다음에 할 일과 계속 가능한 일을 함께 씁니다.
6. **책임 주체를 밝힌다.** 모든 장애요인에 누가 움직여야 하는지 태그(D)를 붙입니다.
7. **면책은 반복한다.** 체류·정책 결과 화면 하단에 푸터(F)를 항상 넣습니다.
